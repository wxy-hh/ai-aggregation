# AI Aggregation - Components (组件设计规范)

本规范定义了平台内各核心 UI 组件在玻璃拟态与 8px 网格系统下的表现形式及状态逻辑。

---

## 1. 按钮 (Buttons)

### 视觉哲学
赋予按钮“微凸起实体按键”的触感。通过 1px 顶部微高光线、微微外扩的复合投影（Z-3）以及悬停时平滑的缩放，诱发点击欲望。点击瞬间提供按压回缩反馈。

### 5 种按钮变体

| 变体名称 (Variant) | 背景材质 | 边框线宽与规格 | 高光及阴影配置 | 适用场景 |
| --- | --- | --- | --- | --- |
| **主按钮 (Primary)** | `linear-gradient(90deg, #2563EB 0%, #4F46E5 100%)` | 无 | 顶部 1px 白高光线；Z-3 级蓝色发光投影 | 核心动作、主 CTA 交互 |
| **次按钮 (Secondary)** | 亮色: `rgba(255,255,255,0.4)`<br>深色: `rgba(15,23,42,0.4)` | 1px solid<br>亮色: `rgba(255,255,255,0.5)`<br>深色: `rgba(255,255,255,0.08)` | 顶部 1px 白高光线；G-2 级毛玻璃模糊；Z-1 级投影 | 常规辅助操作、次级选项 |
| **文字按钮 (Ghost)** | 透明 | 无 | 无背景；Hover 时浮现出 G-1 级极淡磨砂背景 | 极弱操作、选项卡取消按钮 |
| **图标按钮 (Icon)** | 亮色: `rgba(255,255,255,0.3)`<br>深色: `rgba(15,23,42,0.3)` | 1px solid<br>亮色: `rgba(255,255,255,0.5)`<br>深色: `rgba(255,255,255,0.08)` | 正方形居中；G-2 级模糊 | 工具栏图标、侧栏展开汉堡键 |
| **危险按钮 (Danger)** | `linear-gradient(90deg, #EF4444 0%, #DC2626 100%)` | 无 | 顶部 1px 高光线；Z-3 级红色发光投影 | 物理删除、高危退出操作 |

### 6 种状态样式

-   **正常态 (Normal)**：尺寸比例 100%，透明度 100%。
-   **悬浮态 (Hover)**：尺寸微升 `scale-105`，过渡时间 `200ms`。主按钮外发光阴影增强，次按钮背景不透明度提升。
-   **点击态 (Active)**：尺寸微降 `scale-98`，发光投影瞬间收回，呈现明显的按压物理反馈。
-   **聚焦态 (Focus)**：键盘 `Tab` 聚焦时，强制渲染 2px 粗的可见蓝色 focus ring。
-   **禁用态 (Disabled)**：透明度衰减至 40%，指针为不可点击，移除所有 Hover 和 Scale 效果。
-   **加载态 (Loading)**：文字左侧渲染 14px 宽度滚动 Spinner，指针锁定，避免重复提交。

### 3 种标准尺寸

-   **大尺寸 (Large)**：高度 52px，内边距 32px，字号 16px (Semibold)，图标尺寸 20px。
-   **中尺寸 (Medium / 默认)**：高度 44px，内边距 24px，字号 14px (Semibold)，图标尺寸 16px。
-   **小尺寸 (Small)**：高度 32px，内边距 16px，字号 12px (Medium)，图标尺寸 14px。

## 2. 卡片与表面 (Cards & Surfaces)

### 标准卡片 (Standard Card)
-   **背景材质**：亮色 `rgba(255,255,255,0.5)` / 深色 `rgba(15,23,42,0.5)`。
-   **模糊度**：G-3 级深度模糊 (`backdrop-blur-2xl`)。
-   **边框**：`1px solid rgba(255,255,255,0.6)` / 深色 `1px solid rgba(255,255,255,0.1)`。
-   **圆角与阴影**：圆角 `24px`，阴影为 `Z-2` 标准阴影。
-   **性能规避**：若页面内包含极长卡片列表滑动，移动端建议移去模糊，回退至高遮罩实体色。

### Hero 工作台 (Hero Stage Card)
-   **背景材质**：双层渐变遮罩。从顶部 `rgba(255,255,255,0.6)` 到底部透明的渐变。
-   **边缘高光**：卡片上沿必须配置 1px 的白色微发光线。
-   **圆角与阴影**：圆角 `48px`，阴影为 `Z-4` 复合阴影，在其边缘配置极淡的氛围光团。

### 紧凑型卡片 (Compact Card)
-   **背景材质**：亮色 `rgba(248,250,252,0.7)` / 深色 `rgba(24,34,48,0.7)`。
-   **圆角与阴影**：圆角 `16px`，阴影为 `Z-1` 极轻阴影。适用于快捷选项、近创作文件项。

## 3. 输入框 (Inputs)

### 视觉隐喻
采用“向内凹陷”的微阴影视觉隐喻，使用户产生空间下陷的聚焦感。

### 状态量化参数

-   **正常态 (Normal)**：高度 44px，圆角 `12px`。背景亮色 `rgba(255,255,255,0.8)` / 暗色 `rgba(15,23,42,0.8)`。常规边框。
-   **悬浮态 (Hover)**：边框颜色加深（亮色 `border-slate-300` / 暗色 `border-slate-700`）。
-   **聚焦态 (Focus)**：背景透明度降低变实（亮色 `bg-white/95` / 暗色 `bg-slate-950/90`），聚焦背光起效（`bg-blue-500/10` 扩散 6px 的呼吸发光圈），边框变科技蓝。
-   **错误态 (Error)**：描边替换为红色半透明 `border-rose-500/60`，聚焦时背光呈淡红。
-   **成功态 (Success)**：描边替换为绿色半透明 `border-emerald-500/60`，聚焦背光呈淡绿。

### 结构间隙规则
-   标签位于输入框上方 `8px`，辅助或错误文字位于下方 `6px`（报错使用 `text-rose-500`）。
-   前后缀图标距离两侧边缘必须为 `16px`，图标尺寸限制在 16px 宽高等宽。

## 4. 标签与状态胶囊 (Status Badges)

所有胶囊统一采用弹性居中对齐、行高 1，高圆角胶囊形态。

| 胶囊类型 | 背景填充 | 文本颜色 | 适用状态场景 |
| --- | --- | --- | --- |
| **默认状态** | `var(--surface2)` | `var(--text2)` | 常规中性参数标签、只读元数据 |
| **品牌状态** | `var(--accent-subtle)` | `#3B82F6` (亮) / `#60A5FA` (暗) | 激活选项、当前推荐、高亮标记 |
| **成功状态** | `#F0FDF4` | `#10B981` | 任务已完成、AI 执行成功 |
| **警告状态** | `#FFFBEB` | `#F59E0B` | 任务等待中、排队中、余额偏低 |
| **错误状态** | `#FFF1F2` | `#E54350` | 运行失败、接口超时异常 |

## 5. Header 导航栏 (Header Navbar)

### 阻尼感动态融合玻璃设计 (Z-3 层级)
-   桌面端高度为 `72px`，移动端高度为 `60px`。
-   **滚动激活阈值**：页面向下滚动 `scrollY > 10px` 为激活点。
-   **静止态（距顶 0）**：背景完全透明，不显示底部边框和投影。
-   **滚动激活态**：激活 G-3 级深度模糊 `backdrop-blur-2xl`，背景变更为半透明（亮色 `bg-white/70`，深色 `bg-slate-950/75`），底部加一条细切边边框并激活 `Z-3` 级阴影。
-   **导航项激活指示**：在当前激活链接的正下方 2px 处渲染一条 `w-4 h-0.5 rounded-full bg-blue-50`（或 blue-500）指示线，附加外溢发光。

## 6. Modal 弹框与 Drawer 抽屉 (Z-5 顶级覆盖)

### 漂浮舱视觉设计
遮罩层模糊度调高，让弹窗底板带有微弱的蓝色内发光（`inset 0 0 40px rgba(59, 130, 246, 0.05)`），建立深邃的悬浮独立舱体感。

-   **弹框规格**：`sm` (400px，简易询问)；`md` (600px，标准表单)；`lg` (800px，数据分析工作台)；`full` (全屏)。
-   **圆角与内边距**：圆角 `24px`，移动端从下方滑入时自动切换为 `rounded-t-[20px] rounded-b-none`。内边距统一 `24px`，尾部按钮栏做内凹暗色底面。
-   **遮罩层配置**：`bg-slate-950/50 backdrop-blur-md`（8px 页面深度虚化）。
-   **抽屉单边阴影**：抽屉属于长边贴墙容器，只在非贴墙的自由长边缘投射 Z-5 级指向性侧边阴影，并渲染贴墙 1px 描边。

## 7. 组件一致性自检清单 (Checklist)

开发人员在产出代码时必须进行以下自检：

1.  **[ ] 模糊滤镜性能**：大容器（弹层/导航栏）是否配置 `backdrop-blur-2xl`，小按钮和密集列表是否移除了模糊以维护滑动性能？
2.  **[ ] 顶部高光微线**：Primary 按钮、次按钮、模态底板的顶部是否叠加了 `1px` 半透明白色高光切线？
3.  **[ ] 聚焦可访问性**：所有可点击控件被 Tab 键聚焦时是否都有 `ring-2 ring-blue-500` 蓝色边框？
4.  **[ ] 复合阴影防脏**：阴影是否使用了多层柔影（Z-1 至 Z-5），杜绝了脏黑单影？
5.  **[ ] 8px 网格规范**：所有边距、组件高度、Gap 是否严格为 8px 的倍数？
