### 品牌色阶（科技蓝主色，配合梦幻紫与玫瑰粉）

为了营造极致未来感与科技质感，本系统采用科技蓝作为发光核心主色，辅以紫色与粉色高光。

*   **科技蓝 (Technology Blue)**：主交互色，用于点击焦点、激活指示线及核心发光核。
    *   `blue-500` / `#3B82F6`
    *   `blue-600` / `#2563EB`
*   **梦幻紫 (Dream Violet)**：辅助色，用于增加艺术质感及次要背光晕。
    *   `violet-500` / `#8B5CF6`
    *   `violet-600` / `#7C3AED`
*   **玫瑰粉 (Rose Pink)**：图形与渐变高光色，用于营造流光效果与装饰色。
    *   `pink-500` / `#EC4899`
*   **靛青色 (Indigo Blue)**：用于多色渐变的过渡桥梁。
    *   `indigo-500` / `#6366F1`

### 状态色

| 语义通道 | 亮色底板背景 (50) | 核心语义色 (500) | 深色底板背景 (900) |
| --- | --- | --- | --- |
| 成功 (绿) | `#F0FDF4` | `#10B981` | `#14532D` |

### 间距原语 (8px 网格)

`[0, 2, 4, 8, 12, 16, 24, 32, 40, 48, 64, 96]` (全部为 8 像素的整数倍，保证版面完美的韵律感)

### 圆角原语

`[0, 8, 12, 16, 24, 32, 48, 999]` (角哲学为“软，但不糯”。小控件如按钮使用 `12px`，大容器如弹窗使用 `24px-32px`，胶囊使用 `999px`)

## 1. 字体系统

### 字体栈

| 角色 | 字体名称 | 后备字体 | 界面用途 |
| --- | --- | --- | --- |
| 标题级 (Display) | `"Space Grotesk"` | `system-ui, sans-serif` | H1/H2 大标题、核心发光文字 |
| 正文级 (Body) | `system-ui` | `-apple-system, sans-serif` | 正文、按钮、表单、标签 |
| 宽度等宽 (Mono) | `"JetBrains Mono"` | `ui-monospace, monospace` | 代码示例、技术参数、元数据 |

### 字体大小与行高标准（H1-H6 标题系统）

为了解决在磨砂玻璃折射下轮廓发虚的问题，所有重要标题必须使用 Semibold (600) 以上字重。

| Token | 字体大小 (Size) | 行高 (Line Height) | 字间距 (Letter Spacing) | 适用场景 |
| --- | --- | --- | --- | --- |
| `--display` | 60px | 1.08 | -0.025em | 极简风格大标题、Slogan |
| `--h1` (H1) | 36px (移动) / 60px (桌面) | 1.10 | -0.05em | 页面一级主标题、带渐变发光核 |
| `--h2` (H2) | 30px | 1.25 | -0.03em | 侧边栏标题、功能首屏标题 |
| `--h3` (H3) | 24px | 1.35 | -0.02em | 模块级卡片标题 |
| `--h4` (H4) | 18px | 1.40 | -0.015em | 文件卡片标题、功能区块头 |
| `--body` (Body) | 14px | 1.60 | 0 | 标准正文，提高紧凑度与信息密度 |
| `--body-sm` | 12px | 1.50 | 0 | 辅助说明、最近文件、搜索提示 |
| `--label` (Label) | 10px | 1.00 | 0.05em | 状态标签、小微标 (Badge) |

### 玻璃背景文字可读性优化 (防虚描边)

在明暗对比度多变的磨砂玻璃上，必须确保文字对比度（符合 WCAG 2.1 标准）。对辅助文字或弱对比白字，使用下述类来实现微妙轮廓保护：
```css
.glass-text-sharp {
  /* 在不影响文字本色的情况下，利用极淡的扩散纯黑阴影增强文字边缘清晰度 */
  text-shadow: 0 1px 2px rgba(0, 0, 0, 0.15);
}
```

## 4. 空间阴影系统 (Z-Index Z-0 至 Z-5)

我们的阴影系统基于“主定向阴影 + 环境漫反射阴影 + 边缘高光/内发光”三合一模型叠加：

$$\text{Shadow}_{\text{Total}} = \text{Shadow}_{\text{Directional}} + \text{Shadow}_{\text{Ambient}} + \text{Glow}_{\text{Inner}}$$

| 层级 (Z) | 精确阴影 CSS 参数 | 界面用途定位 |
| --- | --- | --- |
| **Z-0** | `box-shadow: none;` | 基础底板，无悬浮度 |
| **Z-1** | `box-shadow: 0 1px 2px rgba(0, 0, 0, 0.03), 0 1px 1px rgba(0, 0, 0, 0.02);` | 平贴微悬。侧边栏按钮、输入框。 |
| **Z-2** | `box-shadow: 0 4px 12px -2px rgba(15, 23, 42, 0.04), 0 2px 6px -1px rgba(15, 23, 42, 0.03);` | 正常悬起。常规内容卡片、文件项。 |
| **Z-3** | `box-shadow: 0 12px 20px -8px rgba(15, 23, 42, 0.08), 0 4px 10px -2px rgba(15, 23, 42, 0.04);` | 中度浮空。导航栏、悬浮小部件。 |
| **Z-4** | `box-shadow: 0 20px 40px -15px rgba(59, 130, 246, 0.12), 0 8px 20px -10px rgba(0, 0, 0, 0.05);` | 深度悬浮。带有蓝色发光核的Hero卡片。 |
| **Z-5** | `box-shadow: 0 30px 60px -20px rgba(15, 23, 42, 0.25), 0 10px 30px -15px rgba(59, 130, 246, 0.15), inset 0 1px 0 0 rgba(255, 255, 255, 0.1);` | 顶级悬浮。模态框、通知弹窗，附带内发光。 |

## 5. 交互与动效

| 动效参数 | 设定值 | 交互性格说明 |
| --- | --- | --- |
| **缓动曲线 (Easing)** | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 极速响应，随后伴随物理阻尼感平滑匀速收尾。 |
| **快速反馈 (Fast)** | `200ms` | 用于 Hover、点击态、Icon 状态变化、缩放响应。 |
| **慢速过渡 (Slow)** | `300ms` | 大面积容器展开、侧拉抽屉、模态框滑入滑出。 |

交互动效原则为：“Hover 抬升缩放（1.02x 至 1.05x），点击轻微回缩按压（0.98x），禁用态取消动效并降低透明度至 40%”。

## 6. 氛围背光 (Hero Stage)

- **渐变背景样式**：`dynamic-mesh`（三色动感光斑融合）。
- **底色方案**：科技蓝（`rgba(59, 130, 246, 0.1)`）、梦幻紫（`rgba(139, 92, 246, 0.1)`）、玫瑰粉（`rgba(236, 72, 153, 0.1)`）混合，带有超轻微的脉冲（Pulse）呼吸感。
- **定位**：背景层只负责虚化和视觉汇聚，不能抢夺上方操作组件与核心文本的对比度。
