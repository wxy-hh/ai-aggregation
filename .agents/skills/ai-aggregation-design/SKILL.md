# ai-aggregation-design

你是本项目极致未来感与轻盈通透视觉风格的捍卫者。启用本技能后，你的核心任务是**借鉴并高保真地映射**项目根目录下 [DESIGN.md](file:///Users/weixiaoyu/Desktop/practice/AI-aggregation/DESIGN.md) 以及设计模型定义的视觉语言：科技蓝主色（配合梦幻紫与玫瑰粉）、磨砂玻璃层级、柔光物理阴影体系、紧凑的 8px 网格、以及清晰的落焦和操作反馈。

你要优先判断“当前页面适合借多少”。对于非常规表单和营销页，只保留配色、圆角、边框、阴影和动效气质，绝不能生硬照搬工作台大框架。

在开始任何实现前，先声明所需字体（标题 `Space Grotesk`，正文系统 Sans），并按照 [`references/platform-mapping.md`](references/platform-mapping.md) 的方式在 HTML/Tailwind 配置中予以加载。

## 1. 设计哲学与核心价值

-   **轻盈通透 (Transparency)**：使用带有磨砂质感的半透明玻璃材质，配合极细的 `1px` 顶部高光线，打破沉重感。
-   **极致未来感 (Futuristic Quality)**：以科技蓝作为发光核，引入紫色、粉色构成平滑的多色背光渐变，带来数字宇宙的呼吸感。
-   **克制秩序 (Disciplined Order)**：所有的发光折射与磨砂面板皆服务于功能层级。大面积文本和数据表严禁开启高模糊，须保持实体高对比度，确保易读性。
-   **层级深邃 (Depth Hierarchy)**：借助精密的 Z-0 至 Z-5 的 6 级物理阴影体系，在页面上确立清晰的三维深度差。

## 2. 组合规则与层级分工

### 空间 Z 轴分工

| 层级 | 对应物理意义 | 视觉表现与参数 | 核心组件实例 |
| --- | --- | --- | --- |
| **Z-0** | 基础底板层 | 实体底色（亮 `#F3F5FA`，深 `#020617`），不加杂质 | 页面基础底板 |
| **Z-1** | 平贴微悬层 | 实体或微透明底，极细 1px 常规描边，Z-1 级轻阴影 | 侧栏按钮、平铺输入框 |
| **Z-2** | 正常悬起层 | `backdrop-blur-xl` 标准玻璃，Z-2 级正常漫反阴影 | 内容卡片、最近创作文件项 |
| **Z-3** | 中度浮空层 | `backdrop-blur-2xl`，带有 G-3 级边框，Z-3 复合阴影 | 浮动导航栏、悬浮操作面板 |
| **Z-4** | 深度悬浮层 | `backdrop-blur-2xl` + 底部渐变消融，Z-4 蓝色发光阴影 | 大尺寸 Hero 区域工作台卡片 |
| **Z-5** | 顶级覆盖层 | 遮罩黑底（带 8px 深度虚化），Z-5 复合强阴影与内发光 | 模态对话框、侧边抽屉、气泡通知 |

### 核心设计原则

1.  **先判别页面，再匹配深度。**
    *   表单页、设置页、列表仪表盘、普通文档 -> **风格借鉴**：仅应用色彩、圆角、边框、阴影和动效，**保持原有骨架结构**。
    *   工作台主页、智能对话页 -> **结构借鉴**：可复用 Hero 区 + 输入 + 卡片阵列的桌架，必须询问确认。
2.  **强调色只服务行为。** 科技蓝（`#3B82F6`）及发光背光属于贵重资源，只能用于主 CTA、激活项、落焦反馈，不得用于铺底。
3.  **圆角有阶梯。** 按钮和输入框统一 `12px`，标准卡片 `24px`，大容器或模态框 `24px-32px`，大外层英雄工作台 `48px`，胶囊永远为 `999px`。
4.  **玻璃必须配边框与高光。** 半透明玻璃必须带有半透明边框（亮色 `border-slate-200/50`，深色 `border-white/10`），且 Primary/Secondary 组件顶部配有一道 `1px` 微白色高光线。
5.  **标题重，正文轻。** 标题字重不低于 600 以抗发虚；磨砂玻璃上的白色或弱对比度文字必须叠加 `text-shadow: 0 1px 2px rgba(0, 0, 0, 0.15)` 轮廓描边。

## 3. 设计反模式 (禁忌)

-   **⚠️ 玻璃套玻璃（套娃）**：严禁在带有 `backdrop-blur` 的大面板里塞入同样带 `backdrop-blur` 的小卡片（导致 GPU 严重卡顿且视觉混乱）。
-   **⚠️ 在嘈杂对比背景上裸奔白字**：背景图有黑白线干扰时，玻璃上的文字未配置 `.glass-text-sharp` 描边或未加纯色遮罩板。
-   **⚠️ 脏黑的单层投影**：使用类似 `shadow-[0_4px_10px_rgba(0,0,0,0.5)]` 的沉重黑影，破坏了玻璃的通透性。
-   **⚠️ 移动端大面积滥用模糊**：在需要高频滑动的长列表上叠加 `backdrop-blur` 造成滑动掉帧。
-   **⚠️ 大圆角一把梭**：给按钮配置过大圆角（按钮只允许 `12px`），或者最外层工作台配置了小圆角。

## 4. 失败模式与兜底恢复

| 触发条件 | 一线修复动作 | 仍失败兜底方案 |
| --- | --- | --- |
| 项目根目录 [DESIGN.md](file:///Users/weixiaoyu/Desktop/practice/AI-aggregation/DESIGN.md) 读取失败 | 转向读取 `design-model.yaml` + `references/tokens.md` 提取 6 级阴影与组件参数 | 使用内置精简集：底色 `#F3F5FA`/`#020617`、主色 `#3B82F6`、系统 Sans、卡片圆角 `24px`、输入圆角 `12px`，并在输出中标注“缺少 DESIGN.md，已启用内置精简集” |
| `references/` 参考文件全部缺失 | 尝试读取全局 `DESIGN.md` 并从中手动构建 Token 变量映射表 | 抛出警告，通知用户规范缺失，使用默认兜底方案 |
| 移动端/小屏滚动时模糊渲染卡顿 | 媒体查询在宽 `<1024px` 时自动移除所有 `backdrop-blur`，替换为 `bg-white/90` 实体遮罩 | 降级为冷灰 `#FAFAFA` 纯色卡片，圆角及阴影参数保持不变 |
| 字体 Space Grotesk 加载失败 | font-family 优雅回退：`'Space Grotesk', system-ui, sans-serif` | 全部降级为系统默认无衬线字体，增大字重对比度以弥补风格差 |
| Squint Test（眯眼测试）未通过 | 强化 L3 主操作与发光背光（增加阴影到 Z-4），加大非关键区域的留白 | 将次要的辅助容器透明度调低，使视觉重新落焦到核心任务上 |

## 5. 设计工作流

1.  **声明字体与图标库**：Space Grotesk、系统 Sans、JetBrains Mono，引入 Lucide 图标。
2.  **获取规范源**：读取全局 [DESIGN.md](file:///Users/weixiaoyu/Desktop/practice/AI-aggregation/DESIGN.md) 作为最高指导事实源。如果缺失，启动 §4 恢复程序。
3.  **🛑 借鉴深度判定**：核对页面属性是“风格借鉴”（不改动页面骨架）还是“结构借鉴”（工作台桌架），确认判定后继续。
4.  **引入 6 级阴影与颜色**：在亮色模式里确立页面分层关系（Z-0 至 Z-5），然后再映射至深色模式以防对比度丢失。
5.  **植入 1px 高光与物理动效**：配置组件的 hover 抬升和 active 缩放，加入 `@layer utilities` 的 Safari 兼容性玻璃层回退处理。
6.  **🛑 Squint Test 校验**：眯眼查看，检验主 CTA（科技蓝 + 发光投影）与状态胶囊（成功/警告/错误）是否能在磨砂背景上最显眼。
