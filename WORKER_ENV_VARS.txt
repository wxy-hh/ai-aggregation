# Worker 部署环境变量模板

此文件只记录变量名和配置说明，禁止填写任何真实凭证。请在 Railway、Render 或其他部署平台的环境变量面板中配置真实值。

```env
# 运行环境
NODE_ENV=production

# 数据库与 Redis。必须与 Web 应用使用同一套资源。
DATABASE_URL=
REDIS_URL=
REDIS_TLS=
REDIS_HOST=
REDIS_PORT=
REDIS_PASSWORD=
REDIS_KV_REST_API_URL=
REDIS_KV_REST_API_TOKEN=
REDIS_KV_REST_API_READ_ONLY_TOKEN=
REDIS_KV_URL=

# AI 服务商
ARK_API_KEY=
ARK_BASE_URL=
ARK_MODEL=
DASHSCOPE_API_KEY=
ZHIPU_API_KEY=
DEEPSEEK_API_KEY=
SILICONFLOW_API_KEY=
SILICONFLOW_API_URL=
SILICONFLOW_DEFAULT_MODEL=
XUNFEI_API_PASSWORD=
XUNFEI_APP_ID=
XUNFEI_API_KEY=
XUNFEI_API_SECRET=

# 对象存储（按需配置）
S3_ENDPOINT=
S3_ACCESS_KEY=
S3_SECRET_KEY=
S3_BUCKET=
OSS_ACCESS_KEY_ID=
OSS_ACCESS_KEY_SECRET=
OSS_BUCKET=
OSS_REGION=
```

实时语音转写 Cloudflare Worker 不读取本文件；请通过 Cloudflare Secret 单独配置：

```text
XUNFEI_APP_ID
XUNFEI_API_KEY
XUNFEI_API_SECRET
BILLING_API_URL
RTASR_GATEWAY_SECRET
```

其中 `RTASR_GATEWAY_SECRET` 必须与 Web 端的同名变量保持一致，真实值不得写入仓库。
