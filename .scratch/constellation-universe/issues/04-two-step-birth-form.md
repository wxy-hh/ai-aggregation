# 04 — 两步出生资料表单

**What to build:** 用户从首页主按钮进入两步表单。第一步：昵称（可选）、阳历出生日期（必填）、关注主题单选四胶囊、隐私说明、日期填写后的太阳星座预览条；第二步「时间校准台」：三档时间精度分段控件（准确到分钟/大约时段/完全未知）、时分选择器配小型可视化钟面（不默认任何推测时刻）、全球城市搜索（必须精确选中，保存经纬度与 IANA 时区）、时区可读确认条、资料影响说明（先讲可得、后讲边界）。右侧（移动端为表单上方）持续展示成品星盘预览与「你将获得」价值摘要；用户填完日期后预览星盘的太阳节点动画滑到其真实星座位置。字段校验内联安静反馈；测算期间改事实的字段禁用但保留已填信息。

**Blocked by:** 03 — 入口首页与成品示例星盘（复用星盘预览组件与价值摘要）

**Status:** ready-for-agent

- [ ] 始终两步、骨架不变；关注主题可空单选；时间精度仅三档
- [ ] 预览星盘太阳节点随阳历日期真实滑动（前端确定性计算，不依赖计算域接缝）
- [ ] 城市未精确匹配不允许提交；未来日期/非法日期字段下即时中文反馈；修正成功红色平滑过渡为平台蓝
- [ ] 完全未知档显示无宫位说明卡（双列「可看到/可解锁」，解锁视角、不置灰），提交按钮旁标注「将生成无宫位本命盘」
- [ ] 主按钮「绘制我的星盘」、次按钮「返回上一步」，热区 ≥44×44；移动端键盘弹出时主按钮保持可见
- [ ] 步骤间横滑约 250ms，返回保留已填内容；`pnpm typecheck` 与 `pnpm lint` 通过
