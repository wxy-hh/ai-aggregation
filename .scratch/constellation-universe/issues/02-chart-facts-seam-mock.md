# 02 — 真值接缝：computeChartFacts 接口与 mock 计算域

**What to build:** 建立全模块唯一的新接缝：占星真值计算域接口，输入出生档案、输出结构化星盘真值（行星/星座/度数/宫位/相位/角点/稳定性标记），数据模型严格符合设计文档 §9.3。前端先行期以 mock 实现交付：内含固定虚拟档案「1995-10-08 14:30 上海」经真实口径冻结的示例盘数据，以及三档时间精度（准确到分钟/大约时段/完全未知）各自的代表性输出。配套金样测试锁定降级与稳定性规则，未来真实星历服务落地时只换实现、不动 UI。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 接口与 §9.3 八实体类型定义落地，事实层字段不含任何 AI 生成内容
- [ ] mock 覆盖三档时间精度：准确到分钟（完整盘）、约时（部分事实标记不稳定并隐藏）、完全未知（无宫位、无上升/天顶、仅稳定事实）
- [ ] 金样测试：约时区间稳定性校验、未知时间月亮跨座隐藏、不以中点或 12:00 补算、不稳定字段为 null 而非伪单值
- [ ] 示例盘数据为真实计算口径冻结，行星位置与相位关系自洽（非手工摆位）
- [ ] 测试先行实践参照 bazi-chart.test.ts；`pnpm typecheck`、`pnpm lint` 通过
