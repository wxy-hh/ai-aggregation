# 06 — 结果页首屏：护照、主轴、大三要素与交互星盘轮

**What to build:** 用户进入结果页首屏，只面对一个核心结论：宇宙护照头（昵称、资料摘要、时间精度标签、盘面依据入口、极淡扫描光入场）→ 一句主轴（18–28 字、clamp(40px, 4vw, 56px)、阅读焦点）→ 大三要素三卡（术语层/白话层/行为层，40ms 间隔上浮入场）→ 520px 以上交互星盘轮（首屏视觉主角，与主轴构成「上句下盘」）。星盘轮轮上仅符号与度数；悬停/键盘聚焦出中文名 tooltip；点选星体出白话先行的事实卡；提供等价文本清单。右侧 4 栏洞察轨：盘面范围与补全入口、分享/星语问答/重新测算。真值先行渲染，解读以 mock 流式填充（落地 20–30 条黄金主轴样例库作为 mock 数据源与文案基准）。不足 960px 折为单列。

**Blocked by:** 05 — 加载页与共享元素转场

**Status:** ready-for-agent

- [ ] 首屏仅护照头、主轴、大三要素、星盘轮四区域；本周行动三角与生活模块不进入首屏
- [ ] 长文区域实体高对比底，仅 Hero 容器玻璃质感；页面无横向滚动
- [ ] 星盘轮键盘可选中关键星体、等价文本清单可用（白话默认、术语折叠「查看全部」）
- [ ] 主轴由至少两项真值共同支持、不超 28 字、不绝对化；黄金样例库 20–30 条落地
- [ ] 洞察轨不含本周行动三角；盘面依据可展开计算口径
- [ ] `pnpm typecheck` 与 `pnpm lint` 通过
