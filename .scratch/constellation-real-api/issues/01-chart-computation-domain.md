# 01 — 真实星盘计算域与金样冻结

**What to build:** 服务端计算域用真实星历库（circular-natal-horoscope-js）产出本命盘与当周行运真值：准确到分钟出完整盘（含宫位四轴）；大约时段做区间采样稳定性校验，不稳定字段标记并隐藏；完全未知出无宫位降级盘并对月亮等快星体做跨座检测；时区按城市自带 IANA 时区 + Intl 求出生当日真实偏移（含夏令时）；高纬度 Placidus 失效自动回退 Whole Sign 并在事实层标注；行运以请求时刻所在自然周窗口按日采样当前天象、筛出与本命星体的主要相位产出 TransitFact。入口首页示例盘用真实引擎重新冻结并替换引用，保证示例与真实产出同口径。本票不接路由，单测全绿即可验证。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 同一出生资料重复计算结果一致；换出生日期/城市/时间结果真实不同
- [ ] 冻结示例盘（1995-10-08 14:30 上海）经权威星历来源人工核对一次后冻结为金样，单测通过
- [ ] 时区与夏令时、约时区间稳定性、未知时间月亮跨座降级、高纬 Whole Sign 回退、相位容许度版本化均有纯函数单测
- [ ] 行运窗口计算与相位筛选有单测，输出 TransitFact 结构符合设计文档 §9.3
- [ ] 入口首页示例星盘渲染改用真实引擎重冻结的档案，视觉无回归
- [ ] 星历库及其 moment 系依赖只在服务端使用，不进客户端包
