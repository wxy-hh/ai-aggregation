# 04 — 星语问答真实化

**What to build:** 报告完成后的星语问答由真实 LLM 驱动：新增 copilot 式问答路由，请求携带报告上下文与用户问题，流式返回答案，回答引用盘面事实且不绝对化。医疗、财务、法律话题由服务端确定性规则（迁移自既有 mock 问答的敏感规则）前置拦截，命中直接返回安全提示与自我观察方向、不过 LLM。每报告最多 3 问，超限给出明确反馈。鉴权、额度预留/结算沿用八字 copilot 模式。前端问答接缝从规则引擎切换为真实请求，面板/抽屉 UI 结构不动。

**Blocked by:** 03 — LLM 流式解读接入

**Status:** ready-for-agent

- [ ] 问答走真实 LLM，回答内容与用户真实盘面一致，不出现模板化万能回答
- [ ] 医疗/财务/法律问题被确定性规则前置拦截，返回安全提示，不产生 LLM 调用与计费
- [ ] 每报告 3 问上限在服务端强制，超限返回明确中文提示
- [ ] 鉴权与额度预留/结算/失败释放行为与八字 copilot 一致
- [ ] 路由测试覆盖敏感拦截（验证不过 LLM）、3 问上限、流式协议；前端问答接缝切换后既有交互无回归
