# 02 — 真实星盘端到端（报告路由 + 前端真值接缝）

**What to build:** 用户填完两步表单提交后，换生日/城市/时间能得到不同的真实星盘：新增单个 SSE 报告路由，先确定性计算本命盘与行运，首事件推 chart-facts，前端真值锁定即转场进结果页、星盘轮可交互；加载仪式四段进度对应真实事件。鉴权与匿名策略沿用八字体系。额度预留发生在真值下发之后——额度不足时星盘照常下发，随后推「解读暂不可用」降级事件，文案区显示锁定卡与登录/充值引导。本阶段 LLM 未接入，解读区统一显示诚实的待接入卡。前端消费方 UI 结构不动，只切换真值异步接缝的实现。

**Blocked by:** 01 — 真实星盘计算域与金样冻结

**Status:** ready-for-agent

- [ ] 报告路由鉴权、匿名免费额度、请求体校验（含未来日期拦截）与八字 report 行为一致
- [ ] SSE 事件顺序 chart-facts 先行，协议含「解读暂不可用」降级事件；前端收到 chart-facts 即转场
- [ ] 三档时间精度的降级可见性正确：未知时间不出现上升/宫位/天顶及依赖 UI，不稳定字段不渲染
- [ ] 额度不足时星盘照常展示、文案区出现锁定卡与引导；匿名用户耗尽免费额度弹既有对话框
- [ ] 加载仪式四段进度由真实事件驱动，2.5–4 秒最小仪式窗保留
- [ ] 真值完成即写入本地统一历史（含修订快照机制），可从历史记录重试
- [ ] 路由测试（模型客户端边界 mock）：事件顺序、降级事件、鉴权分支全绿；既有降级可见性/表单测试回归通过
