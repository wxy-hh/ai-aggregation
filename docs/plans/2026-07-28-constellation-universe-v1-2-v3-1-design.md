# 星座寰宇 V1.2 / V3.1 一致性修订设计

## 目标

将《星座寰宇模块设计文档》的流程、数据与边界设为唯一语义来源，并将 V3 视觉稿收敛为同一套可开发的 P0 状态。此次修订不增加功能，只消除真值、范围、隐私和跨端壳层的冲突。

## 交付边界

- 文档修订为 V1.2，补齐输入、重算、时区、分享和 P0/P1 的明确规则。
- 所有与 V1.2 冲突的 V3 语义改由 V3.1 右侧内容区状态规范覆盖；归档 V3 图稿不再作为开发依据，现有系统壳层不重绘。
- 新增视觉交接清单，明确每一个 P0 右侧内容状态必须包含及禁止出现的内容。
- 不实现应用功能、后端计算或新的产品能力。

## 唯一真相来源

| 层级 | 负责内容 | 约束 |
| --- | --- | --- |
| 主设计文档 | 用户流程、数据模型、计算边界、P0/P1 范围、隐私与安全规则 | 与其他交付物冲突时优先级最高。 |
| 设计系统 | 当前 AI STUDIO 左侧系统导航、命理大师模块侧栏、色板、字号、圆角、图标、组件状态和无障碍基线 | 所有视觉稿必须复用；星座仅能替换右侧内容区，不能重做导航壳层或品牌。 |
| 视觉稿 | 已批准流程状态的布局、信息层级与响应式表现 | 不得新增字段、计算口径、功能入口或产品范围。 |

## P0 产品闭环

1. 命理入口、两步出生资料表单和三档时间精度。
2. 可复现的本命盘真值，未知时间严格降级。
3. 基于真实任务事件的四段加载进度。
4. 结果总览：护照头、一句主轴、大三要素、本周行动三角、五个生活模块、关键相位。
5. 星盘轮的基础点选与等价文本列表。
6. 星语问答的少轮追问、引导问题和敏感主题拒答。
7. 脱敏分享、统一历史记录的写入、回看和删除。

五个生活模块均属于 P0；移动端仅默认展开前三个，用户可展开其余模块。星盘轮复杂连线动画、完整双向索引、完整逐日行运、术语百科和宫位地图的增强交互属于 P1。

## 出生资料与精度规则

表单固定为两步：

1. 昵称（可空）、阳历出生日期（必填）、关注主题（可空且单选）。
2. 时间精度、出生时间或约时时段、全球城市精确匹配、时区可读确认。

时间精度只有三档：

| 精度 | 输入 | 可展示范围 | 标签 |
| --- | --- | --- | --- |
| 准确到分钟 | 用户提供时与分 | 完整本命盘 | 时间精度：准确到分钟；盘面范围：含宫位。 |
| 大约时段 | 用户选择可计算的时间区间 | 仅展示经过区间稳定性校验的角点与宫位结论 | 时间精度：约时；同时显示风险说明。 |
| 完全未知 | 不输入出生时间 | 行星星座、稳定相位和非宫位解读 | 时间精度：未知；盘面范围：无宫位行星盘。 |

“只知道日期”不是第四档：出生日期本来就是必填。未知时间不得默认、推测或展示为 12:00，也不得生成上升、天顶、十二宫或任何宫位依赖的解读。未知时间的结果页不显示“上升待定”事实卡，改为独立的资料范围提示卡。

约时在 P0 开发前必须完成计算域 spike：保存原始时间区间并对区间稳定性做判断；结果不稳定时隐藏对应角点、宫位及依赖结论，不能用时段中点伪装为确定结果。

出生地点为历史出生城市，不提供“使用当前位置”。城市必须精确匹配并保存城市、经纬度和 IANA 时区。展示格式统一为“城市 · IANA 时区 · 当地时间”，历史夏令时换算在“盘面依据”中按需展开；不得混用“北京时间”、GMT 和 UTC 作为未解释的主展示。

## 真值、加载和安全文案

- 前三段加载主语为“系统”或“计算服务”：校准出生地与当地时区、定位行星与月亮、绘制十二宫与关键相位。
- 仅第四段可写“AI 正在基于星盘事实整理宇宙重点”。
- 所有进度只能由对应任务完成事件驱动，禁止虚构百分比。
- 结果精度只使用分类标签和盘面范围，不使用“高”“88%”等无法审计的分数。
- 问答和示例文案不使用“桃花运”“必然”“注定”等泛娱乐或确定性表述；健康、财务、法律、孕育和死亡只提供非结论性的支持与求助建议。

## 历史、分享与重算

- 历史和入口最近记录使用同一脱敏级别：标题、生成日期和低敏摘要；不展示生日、城市、精确时间或度数。
- 分享卡只包含昵称或匿名、可计算的大三要素、主轴和生成日期。未知时间时不展示上升星座。
- 补充同一份出生资料的时间信息可更新逻辑历史记录，并写入 `recalculatedAt`；每次计算保留独立的真值和报告版本，以及 `engineVersion`、`orbTableVersion`、`calculationRevision`。
- 全新出生资料创建新历史记录。旧问答不自动迁移到新事实，旧分享卡按快照保留或按分享策略撤销。

## 跨端视觉规则

- 桌面端固定为当前 AI STUDIO 左侧系统导航与命理大师模块侧栏；星座寰宇是奇门遁甲演化之后的第四个同级模块，只有右侧内容区可变。
- 移动端固定为现有页头、四段命理导航和单一全局底栏。
- 结果阅读态的“问星语、分享、重新测算”不再额外叠加第二条底栏；具体入口样式必须与其他三个命理模块一致。
- 所有状态共享产品名称、Logo、模块图标、副文案、色板、圆角和字号阶梯。
- P0 星盘轮必须有关键星体与相位的文本替代列表、明确焦点、读屏名称及等价操作；复杂空间键盘漫游与连线动画留在 P1。

## V3.1 视觉稿的禁止项

- 未知时间默认 12:00、AM/PM 分支、三步或单页长表单。
- “可多选”关注主题、精度百分比、未定义的性别字段、当前位置。
- 年度运势、元素或模式分布统计、体系切换、高级设置、导出入口、完整今天/7天/30天时间线。
- 与全局历史记录不同的隐私展示、不同产品名称或第二套壳层。

## V3.1 验收

1. 任意一张图都能映射到两步表单和三档时间精度，没有额外状态机。
2. 未知时间图只显示无宫位行星盘范围，不出现上升、天顶、宫位和默认时间。
3. P0 视觉只显示已定义的 P0 能力；P1 画面有明确阶段标记，且不作为 P0 导航入口。
4. 桌面与移动端均复用同一真实产品壳层；移动端没有双底栏遮挡安全区。
5. 文案遵循统一 Copy Deck，所有用户可见文本为中文，时区、术语和数字格式一致。
