# 0027. 知识库 FAQ 标准问答对管理与双轨精准短路架构

* **状态**：已接受；第 3 节的双轨场景边界与匹配/计数政策由 ADR-0055 部分取代，其余继续有效
* **日期**：2026-10-26
* **决策者**：AI 聚合平台工程团队
* **范围**：`packages/db`（Prisma 模型与向量化扩展）、`apps/web`（知识库 FAQ 管理工作台、API 路由、检索短路调度器）、`packages/shared`（FAQ 实体类型与检索阈值契约）

---

## 背景

在基于长文本分块的通用 RAG 架构（ADR-0021）中，文本切片粒度通常在 500~800 tokens 之间。当用户咨询企业制度、标准客服、常见术语定义等高频且具备明确标准答案的问题时，长文本检索存在固有瓶颈：
1. **语义匹配发散 (Sentence-to-Paragraph)**：用户提出的简短问题在与段落切片匹配时，常召回包含大量冗余背景的段落，导致大模型回答发散、抓不住核心官方口径，甚至偶发幻觉；
2. **推理成本与延迟浪费**：对于答案高度确定且一字不可更动的问题（如开票税号、退款时限），仍必须调用多轮 LLM 推理，产生额外的 Token 计费与秒级等待；
3. **运维更新滞后**：若要调整某一标准答案口径，长文档模式下必须重新编辑源文件、重新上传、全量切片并重新计算整篇向量，无法做到特定口径的单条毫秒级即时生效。

因此，亟需引入 FAQ 标准问答对作为知识库精度的压舱石，并在检索层构建确定性短路与权威口径加权机制。

---

## 决策

### 1. 实体分层与多租户 ACL 隔离

我们将 FAQ 问答对作为独立于非结构化长文档（`Document`）的一等公民资产进行建模：
- **主实体 `KnowledgeFaq`**：归属于特定知识库（`knowledge_base_id`），同时物理冗余 `user_id`（用于 SQL 层强行前置防越权隔离）；包含标准问题（`question`）、权威答案（`answer`）、启用开关（`enabled`，支持一键启停而不物理删数据）及使用统计；
- **生命周期独立**：FAQ 增删改查完全独立于长文档生命周期，具备专用 API 路由与前端管理卡片。

### 2. 问法扁平化与独立向量索引 (Sentence-to-Sentence)

为彻底解决问答向量匹配的语义稀释（Vector Smearing）问题：
- **独立问法表 `KnowledgeFaqQuestion`**：不将主问题与所有相似问拼成长字符串向量化，而是建立一对多子表，将标准原问与每个相似问（`FaqSimilarQuestion`）分别作为一条独立记录进行稠密向量化（1024 维 BAAI/bge-m3 + HNSW 索引）与 jieba 中文词法分词（`tsvector`）；
- **语义锐度最大化**：每一个问法都是干净的短句对短句匹配，保证余弦相似度（Cosine Similarity）能够稳定触达高阈值；任一相似问命中即可直接定位到主 FAQ。

### 3. 双轨精准短路与权威口径注入 (FaqShortCircuit & FaqGroundTruth)

在检索与对话调度管道中引入置信度双轨机制：
- **极高置信度前置强短路（$\text{Cosine} \ge 0.92$）**：
  - 在常规单轮问答或指定知识库提问时，若提问与 FAQ 匹配度达到 $\ge 0.92$，直接截断大模型推理流，将 FAQ 标准答案秒级直出给用户；
  - **收益**：100% 确定性、零幻觉、零 Token 消耗、百毫秒级极致响应。
- **强相关权威口径注入（$0.78 \le \text{Cosine} < 0.92$）**：
  - 在相似度处于该区间，或会话处于智能体多步推理（Agentic Tool Call）时，不执行强截断，而是将命中的标准问答作为 `FaqGroundTruth` 注入模型提示词顶部，强约束模型优先遵循该官方口径，同时允许模型结合对话历史进行个性化润色。

### 4. 同步即时计算与轻量 CSV 导入导出运维

- **单条增改即时同步**：单个 FAQ 创建或编辑仅涉及 1 个主问题和若干相似问，向量化耗时极短（<150ms），直接在服务端 API 路由内同步完成并落盘，用户保存后立即生效并可在检索调试台中验证；
- **轻量 CSV 运维流**：在前端 `KnowledgeWorkspace` 新增「问答对 (FAQ)」Tab，首期支持基于标准 CSV 格式（列：标准问题、标准答案、相似问）的批量导入与全量导出，不引入重量级三方依赖。

---

## 影响与后果

### 收益 (Positive)
- **核心问答确定性**：彻底消除高频客服与规章制度问答中的偶发幻觉与口径偏离；
- **大幅降本提速**：高频场景命中直接短路，节省大模型 Token 配额，用户体验由秒级等待转为秒开直出；
- **敏捷运维**：业务人员修改口径即时生效，极大降低知识库调优与维护门槛。

### 代价与权衡 (Trade-offs)
- 新增了数据库表结构与外键关联，需要执行 Prisma 迁移与 raw SQL 向量索引配置；
- 在检索入口（`knowledge_search` 与流式前置预检）增加了 FAQ 优先分流逻辑，需编写完备的单测以确保无缝兼容普通文档检索。
