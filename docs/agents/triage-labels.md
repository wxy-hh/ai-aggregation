# 分诊标签

技能体系用五个标准分诊角色来描述工作。本文件把这些角色映射到本仓库问题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义                       |
| -------------------------- | -------------------- | -------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该 issue     |
| `needs-info`               | `needs-info`         | 等待上报者补充更多信息     |
| `ready-for-agent`          | `ready-for-agent`    | 需求已完整，可交给 AFK 代理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现               |
| `wontfix`                  | `wontfix`            | 不会被处理                 |

当技能提到某个角色时（例如"应用 AFK-ready 分诊标签"），请使用本表中对应的标签字符串。

按你实际使用的词汇编辑右列即可。
