# 紫微斗数概述

> 来源：[现代数术知识库 - 紫微斗数概述](https://docs.3meta.pub/ziwei/)

## 简介

紫微斗数是中国古代最重要的命理学之一，与八字并称"术数双璧"。它通过分析出生时间对应的星曜分布，来推断人的命运和性格。

---

## 什么是紫微斗数

紫微斗数以紫微星为主星，结合其他108颗星曜在十二宫的分布，分析人的一生运势。"斗"即北斗，"数"即术数推算，紫微星为诸星之首，故名"紫微斗数"。

---

## 历史渊源

相传紫微斗数由五代时期的道士陈抟所创，后经北宋宰相吕蒙正完善。历经千年发展，形成了完整的理论体系。

## 基本构成

### 十二宫位

| 宫位 | 含义 |
|------|------|
| 命宫 | 个性、命运核心 |
| 兄弟宫 | 兄弟姐妹关系 |
| 夫妻宫 | 婚姻感情 |
| 子女宫 | 子女关系 |
| 财帛宫 | 财运状况 |
| 疾厄宫 | 健康状况 |
| 迁移宫 | 外出、变动 |
| 交友宫（奴仆宫） | 人际关系 |
| 事业宫（官禄宫） | 事业发展 |
| 田宅宫 | 不动产、家庭 |
| 福德宫 | 精神享受、福分 |
| 父母宫 | 父母关系、外貌 |

### 主要星曜

#### 十四主星

**北斗星系：**
- 紫微星、天机星、太阳星、武曲星、天同星、廉贞星

**南斗星系：**
- 天府星、太阴星、贪狼星、巨门星、天相星、天梁星、七杀星、破军星

#### 辅助星曜

- **六吉星：** 文昌、文曲、左辅、右弼、天魁、天钺
- **六煞星：** 擎羊、陀罗、火星、铃星、地空、地劫
- **四化星：** 化禄、化权、化科、化忌

## 应用领域

### 命理分析

- **性格分析：** 通过命宫主星了解性格特点
- **事业发展：** 分析事业宫判断职业方向
- **婚姻感情：** 看夫妻宫了解感情状况
- **财运状况：** 通过财帛宫分析财运
- **健康状况：** 疾厄宫显示健康问题

### 流年运势

- **大限：** 每十年一个大限，显示十年运势
- **流年：** 每年的运势变化
- **流月：** 每月的运势起伏
- **流日：** 每日的吉凶变化

### 择日决策

- **结婚择日：** 选择婚姻吉日
- **开业择日：** 选择创业时机
- **搬家择日：** 选择迁移吉时

## 特点优势

### 系统完整

包含命盘、大限、流年等多层次分析体系。

### 预测精准

通过星曜组合和四化分析，可以精确预测事件发展。

### 应用广泛

可应用于命理、择日、风水等多个方面。

### 易学易用

相比八字，紫微斗数更加直观易懂。

## 排盘要素

排一个完整的紫微命盘需要：

1. **出生年份：** 确定命宫位置和星曜
2. **出生月日：** 确定其他宫位和星曜
3. **出生时辰：** 确定命宫度数
4. **性别：** 男女排盘方式不同
5. **农历/阳历：** 需要准确的农历日期
