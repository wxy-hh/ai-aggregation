## 常用计算规则

### 安命宫计算

**公式：**
1. 从寅宫起正月，顺时针数到出生月
2. 从该宫起子时，逆时针数到出生时
3. 所在宫位 = 命宫

**示例：** 三月辰时
```
寅(正月) → 卯(二月) → 辰(三月)
辰(子时) → 卯(丑时) → 寅(寅时) → 丑(卯时) → 子(辰时)
命宫在子宫
```

### 安身宫计算

**公式：**
1. 从寅宫起正月，顺时针数到出生月
2. 从该宫起子时，顺时针数到出生时
3. 所在宫位 = 身宫

**区别：** 身宫是**顺时针**数时辰，命宫是**逆时针**

## 大限起法

### 起大限规则

根据五行局和性别确定：

**阳男阴女：** 顺行
**阴男阳女：** 逆行

**起法：**
1. 从命宫开始
2. 阳男阴女顺时针
3. 阴男阳女逆时针
4. 每十年一个大限

### 大限计算

```
大限起始年龄 = 五行局数
例如：水二局，2岁起大限
     木三局，3岁起大限
     金四局，4岁起大限
     土五局，5岁起大限
     火六局，6岁起大限
```
