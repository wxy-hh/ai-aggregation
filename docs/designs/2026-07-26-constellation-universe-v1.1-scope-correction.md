# 星座寰宇 V1.1 范围修正：只保留完整本命星盘

## 结论

首期不提供“快速星座指引”。该模式只要求生日，却没有独立、可信且值得交付的结果页；它会让星座寰宇从“专业本命星盘”退化为泛十二星座内容，削弱与八字、紫微模块并列时的产品价值。

星座寰宇 V1.1 只有一个入口和一个闭环：

出生资料 → 时区与星盘计算 → 本命总览 → 盘轮、相位、宫位、近期星运 → 星语问答与分享。

出生时间未知不是第二种服务，而是同一闭环的资料精度降级：

- 可计算：太阳、月亮和其他行星的星座位置、可用相位、非宫位的性格与关系解读。
- 不计算：上升、天顶、十二宫、所有依赖宫位的结论。
- 结果页明确说明“补充出生时间后可解锁什么”，不以默认中午时间伪造完整盘面。

## 入口修正

入口只保留一张核心行动卡：

- 标题：绘制你的完整本命星盘。
- 价值说明：太阳、月亮、上升、十二宫、关键相位与近期行运。
- 主按钮：填写出生资料。
- 资料不完整提示：不知道出生时间也可以继续，我们会隐藏无法可靠计算的宫位与上升。

不得出现“快速星座指引”“快速开始”“今日提示”或第二个竞争性入口。

## 对原视觉稿和需求的影响

| 项目 | V1.0 | V1.1 修正后 |
| --- | --- | --- |
| 首屏选择 | 完整本命星盘与快速星座指引并列 | 仅完整本命星盘。 |
| 最低资料 | 快速模式可只填生日 | 生日为必填；出生时间未知可继续。 |
| 结果链路 | 快速模式缺少完整结果定义 | 所有用户进入同一结果框架，依资料精度决定可见模块。 |
| 近期星运 | 容易被误读为通用星座运势 | 仅作为本命盘完成后的个性化行运模块。 |
| 视觉入口 | 两张模式卡分散注意力 | 单一英雄卡 + 资料精度解释，价值更清晰。 |

此前的结果总览、关键相位、星语问答和分享视觉稿仍然有效，因为它们本来就以完整本命盘报告为前提；不存在需要补画的“快速模式结果页”。

## 后续产品边界

如果未来确实要做低输入成本的内容，应作为首页或运营层的独立“每日星象”功能重新立项，并单独定义：

- 目标用户与触发场景；
- 无出生资料时的内容可信边界；
- 独立结果页、留存机制与内容生产策略；
- 与本命星盘的跳转关系。

它不应作为星座寰宇首期入口的一部分。
