# 星座寰宇视觉交付附录（V3.1）

## 交付用途

本附录定义 V1.2 对应的可开发视觉状态。V3 图稿均为归档参考，不能作为开发依据；本文档与 V1.2 主设计文档发生冲突时，按主设计文档执行。

## 共享壳层

- 桌面端：逐像素复用当前 AI STUDIO 左侧系统导航，以及其右侧现有的“命理大师”模块侧栏。模块顺序固定为“八字、紫微、奇门、星座”，星座与奇门是同级模块项。
- 移动端：AI 命理大师页头 + 四段模块导航 + 单一全局底栏。
- AI STUDIO 仅作为现有系统导航上的既有品牌标识保留；星座模块不能复制、改造或另做品牌名称、Logo、侧边栏和底部导航。
- 任何星座状态稿只能替换右侧内容区；左侧系统导航与命理大师模块侧栏必须直接沿用现有实现，不得通过图像生成重新设计。
- 长文阅读区为高对比实体背景；外层英雄区可使用低强度蓝紫玻璃效果；所有用户可见文字使用中文。
- 时间、时区和数字格式固定为“北京 · Asia/Shanghai · 1998 年当地时间”；历史夏令时说明只在“盘面依据”中展开。

## 无障碍与移动端验收

- 可点击图标、分段控件与操作项的热区不少于 44 × 44。
- 星盘轮必须提供包含行星、相位与当前选中项的等价文本清单，焦点与读屏名称清晰可见。
- 阅读态不因模块操作再次压缩全局底栏安全区；结果页只保留一条固定底部区域。
- 图片、星盘和分享卡自适应容器，不产生横向滚动。
