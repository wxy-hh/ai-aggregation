- [ ] **TC-API-01**: `GET /api/agent-runs` 正常拉取用户分页列表，验证 `page`、`limit`、`outcome` 参数有效性与越界兜底；

### 2. 前端客户端与组件测试 (`apps/web/src/components/history/`)
- [ ] **TC-UI-01**: `AgentRunHistoryView` 渲染：空状态、加载态、错误重试态的视觉完整性；
- [ ] **TC-UI-02**: 分页与过滤交互：点击不同状态胶囊重置页码为 1；点击上一页/下一页正确触发参数请求；
- [ ] **TC-UI-03**: 卡片操作与抽屉唤起：点击「详情」呼出详情抽屉，展示 ToolCalls 流水；点击「删除」弹出确认框；
- [ ] **TC-UI-04**: `ProfileShell` 渲染：验证 `ProfilePage` 中不再包含原有长列表，各区块衔接自然。

## 二、端到端真机冒烟验收规范 (E2E & ego-browser)

> **macOS 强制规则声明**：根据 `AGENTS.md` 规范，触及用户可见核心链路（历史与个人中心），阶段 5 审查交付前必须且唯一强制使用 `ego-browser` 弹出真实可见窗口进行验收，继承真实登录态并截图落盘。严禁擅自降级。

### 核心验收场景流 (Smoke Scenarios)

1. **场景 1：`/history` 大厅「智能体」Tab 浏览与统计**
   - 动作：浏览器导航至 `http://localhost:3030/history`，点击顶部「智能体」Tab。
   - 预期结果：
     - Tab 激活状态高亮，显示当前智能体任务总数徽章；
     - 列表呈现卡片网格，展示任务目标摘要、终态标签（成功/部分/失败）、步数、耗时及消耗点数。

2. **场景 2：服务端分页深度测试**
   - 动作：在拥有 14 条任务的前提下，保持默认每页（如 8 或 10 条）。
   - 预期结果：
     - 底部清晰展示分页控件（如 `第 1 页 / 共 2 页`）；
     - 点击「下一页」，平滑切换至第 2 页，展示剩余的 4 条更早记录，彻底解决截断痛点；
     - 点击「上一页」，正常翻回第 1 页。

3. **场景 3：状态过滤与检索**
   - 动作：点击过滤胶囊中的「成功」或「部分」或「失败」。
   - 预期结果：
     - 列表即时过滤为对应状态的任务，总数与页码自适应重算；
     - 点击「全部」重置回全量列表。

4. **场景 4：审计详情抽屉回溯**
   - 动作：在任意卡片点击「详情」。
   - 预期结果：
     - 抽屉自右侧或中间平滑呼出（移动端自底部弹出），展示完整任务目标、指标卡片与具体的工具调用步骤（Tool Calls）；
     - 点击关闭或遮罩正常退出抽屉。

5. **场景 5：一键重跑跳转**
   - 动作：在卡片或抽屉中点击「重跑」。
   - 预期结果：
     - 提示「已载入任务目标，正在前往会话...」；
     - 页面跳转至 `/chat?new=true&agent=true&goal=...`，输入框已预填目标文本，Agent 模式激活。

6. **场景 6：安全删除单条记录**
   - 动作：在某条记录卡片上点击垃圾桶或「删除」按钮，在二次确认弹窗中确认。
   - 预期结果：
     - 提示「运行记录已删除」；
     - 列表自动无感刷新，该项不再显示，总条数减 1。

7. **场景 7：`/profile` 页面瘦身与回归验证**
   - 动作：浏览器导航至 `http://localhost:3030/profile`。
   - 预期结果：
     - 页面整洁美观，不再出现原有的巨大运行记录网格；
     - 基本资料卡、资源消耗卡与下方的邮箱绑定/安全设置自然衔接，无多余留白或布局破损。
