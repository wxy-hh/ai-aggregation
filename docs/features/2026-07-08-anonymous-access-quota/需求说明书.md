# 需求说明书：匿名访问 + 设备指纹 + 额度限制

## Feature ID

`2026-07-08-anonymous-access-quota`

## 背景

当前 AI 聚合平台使用 JWT + refresh_token cookie 的登录认证体系，未登录用户会被 `middleware.ts` 重定向到 `/login`。为了降低用户首次使用门槛、收集早期反馈，需要临时取消登录门槛，改为通过浏览器指纹识别设备，并给每个设备 3000 token 的免费额度。额度耗尽后弹框提示，但允许查看历史记录，禁止新的 AI 调用。

本需求是临时方案，后续仍会恢复登录认证，因此实现必须具备可回滚性。

## 目标

1. 用户无需登录即可直接使用对话、图像、视频、语音等 AI 功能。
2. 通过浏览器指纹生成稳定设备标识，防止简单刷新页面即获得新额度。
3. 每个设备首次访问时自动创建匿名用户，默认额度 3000 token。
4. AI 调用前校验额度，余额不足时返回明确错误码，前端弹框提示。
5. 额度耗尽后仍可查看历史记录，但无法发起新的 AI 调用。
6. 保留现有登录认证代码和真实用户体系，确保后续可回退。

## 非目标

- 不替代现有登录/注册/OAuth 流程。
- 不做严格的反欺诈（设备 ID 可被高级用户伪造，仅做基础防刷）。
- 不做支付/充值/购买额度功能。
- 不迁移或合并匿名用户与真实用户的数据（后续登录升级时另行设计）。

## 关键术语

| 术语 | 说明 |
|------|------|
| 设备指纹 | 通过浏览器属性（Canvas、WebGL、字体、时区、语言等）生成的稳定哈希，用于识别同一设备/浏览器。 |
| 匿名用户 | 无需注册即可使用系统的影子账号，数据库中对应一条 `isAnonymous = true` 的 `User` 记录。 |
| 额度 | 匿名用户的 `User.tokens` 字段，默认 3000，每次 AI 调用按实际 token 消耗扣减。 |

## 需求细则

### FR-1 设备指纹采集

- 使用客户端指纹库采集浏览器指纹。
- 指纹经服务端签名或加盐后生成 `deviceId`。
- `deviceId` 持久化在 `localStorage` 中，下次访问时复用。
- 若用户清除 localStorage，则视为新设备，重新生成并分配新额度。

### FR-2 匿名用户创建

- 当设备首次访问系统时，调用后端接口创建匿名用户。
- 匿名用户的 `username` 使用 `anon_<deviceId 前段>` 并保证唯一。
- 匿名用户的 `passwordHash` 为空。
- 匿名用户的 `tokens` 默认 3000。
- 匿名用户的 `role` 为 `'user'`，`status` 为 `'active'`。

### FR-3 匿名认证

- 匿名用户同样使用 JWT access token 访问 API。
- `requireAuth()` 校验 token 后返回 `userId`，无需关心用户是真实还是匿名。
- 中间件不再因缺少 refresh_token 而重定向到登录页。
- 已登录的真实用户保持原有体验不变。

### FR-4 额度校验与扣减

- 在 AI 调用入口（聊天、图像、视频、语音）发起前检查 `User.tokens`。
- 余额 ≤ 0 时直接返回 `QUOTA_EXHAUSTED` 错误，不调用下游 AI 服务。
- 成功调用后按实际消耗扣减 token，并写入 `AIUsageRecord`。
- 扣减操作需要避免并发超扣（使用数据库原子操作或乐观锁）。

### FR-5 额度耗尽提示

- 前端在收到 `QUOTA_EXHAUSTED` 错误时弹出提示框。
- 提示文案为中文，说明额度已用完，可继续查看历史但无法发起新调用。
- 弹框为非阻塞式模态，用户关闭后仍可浏览页面。

### FR-6 历史记录隔离

- 匿名用户的对话历史、图像历史、语音历史、任务记录与真实用户完全隔离。
- 额度耗尽不影响历史记录的读取和展示。

### FR-7 后续登录回退兼容性

- 不修改现有真实用户登录、注册、OAuth 回调、refresh token 流程。
- 数据库变更仅增加 `isAnonymous` 字段，不影响现有真实用户数据。
- 匿名用户后续可选择升级为真实账号（不在本需求范围内，但数据结构需预留）。

## 安全与隐私

- 设备指纹仅用于生成匿名用户标识，不上报敏感个人信息。
- 匿名用户的 `deviceId` 在传输和存储中需做哈希处理，避免直接存储原始指纹。
- 额度扣减需防止并发扣成负数。

## 验收标准

- [ ] 未登录用户可直接访问 `/chat`、`/image`、`/video`、`/voice`、`/history` 等页面。
- [ ] 首次打开页面时自动生成匿名用户并显示 3000 token 额度。
- [ ] 多次刷新页面后仍是同一匿名用户，额度和历史不变。
- [ ] AI 调用成功时正确扣减额度。
- [ ] 额度耗尽后再次发起 AI 调用时弹出提示框，且下游 AI 服务未被调用。
- [ ] 额度耗尽后仍可正常查看历史记录。
- [ ] 现有登录用户流程、额度、历史不受影响。
- [ ] 类型检查、lint、构建通过。
