# 多模型聚焦比较对话 实现计划

> **使用说明：** 按照 `Depends on` 依赖关系执行。每步使用 checkbox (`- [ ]`) 语法跟踪进度。

**目标：** 在 `/chat` 新增「并行对比」模式：同一 Prompt 并发 2–4 个模型，模型概览轨道 + 双列聚焦阅读 + 焦点替换 + 分支隔离多轮 + 单模型停止/重试，并持久化比较会话（刷新可恢复），全程遵循 DESIGN.md 美学与移动端自适应。

**技术方案：** 新建独立 `comparison-store`（zustand）负责比较运行时编排（并发流式、分支隔离、停止/重试、焦点槽位），复用现有 `/api/chat` 由前端发起 N 条并发 SSE 请求；扩展现有 `conversations-store`（localStorage 持久化）承载「会话→轮次→模型分支」结构；比较视图作为 `/chat` 内独立组件，由页头分段控制在「单聊 / 并行对比」间切换，单聊保留现有实现。

**技术栈：** Next.js 15 + React 19 + TypeScript、Zustand（persist→localStorage）、Tailwind + shadcn/ui、Vercel AI SDK SSE（复用 `consumeChatResponse`）、`authFetch`。

## 全局约束

- **中文优先**：所有 UI 文案、注释、错误信息用中文。
- **不改既有单聊**：`mode === 'single'` 时走现有逻辑，零行为变化。
- **复用 `/api/chat`**：比较模式由前端并发调用，不新增 provider 接入；doubao 走 Responses API、xunfei 走 chat completions，均输出标准 SSE。
- **分支隔离**：每个模型独立 `branchMessages` 与 `AbortController`，绝不串上下文；重试/停止不得重复扣减 token。
- **DESIGN.md**：玻璃拟态容器级 G-2/G-3、长文阅读区实体高对比背景（忌玻璃套玻璃）、柔光 Z 轴阴影、科技蓝/靛青渐变、8px 网格、`duration-200/300` + `cubic-bezier` 缓动、中文文案。
- **移动端优先**：安全区适配、≥44×44 热区、底部抽屉、单主滚动容器。
- **money 风险**：发送按钮旁可见「将同时调用 N 个模型」成本提示。
- **导入规范**：直接路径别名 `@/`；跨 app 引用走 `packages/`。
- **状态管理**：Zustand + `useShallow`，store 从 `@/stores` 导入。

export type ProviderName = 'xunfei' | 'doubao';

  model: string;        // 变体 id，如 'generalv3.5'

  label: string;        // '讯飞星火 · Spark Max'
}

export type ModelRunStatus = 'queued' | 'streaming' | 'completed' | 'failed' | 'stopped';

export interface BranchMessage {
  role: 'user' | 'assistant';
  content: string;
}

export interface ModelRun {
  modelKey: string;      // `${provider}:${model}`
  provider: ProviderName;
  model: string;
  label: string;
  status: ModelRunStatus;
  startedAt?: number;
  completedAt?: number;
  content: string;
  error?: string;
  truncationWarning?: string;
  branchMessages: BranchMessage[]; // 该模型独立上下文
}

export interface FocusSlots {
  left: string;  // modelKey
  right: string; // modelKey
}

export interface ComparisonTurn {
  id: string;
  prompt: string;
  createdAt: number;
  runs: Record<string, ModelRun>; // key = modelKey
  focusSlots: FocusSlots;
}

export function toModelKey(provider: ProviderName, model: string): string {
  return `${provider}:${model}`;

import type { ComparisonTurn, SelectedModel } from '@/types/comparison';

export function createComparisonHistoryItem(
  conversationId: string,
  turns: ComparisonTurn[],
  selectedModels: SelectedModel[]
): Omit<ChatHistoryItem, 'id' | 'createdAt' | 'updatedAt'> {
  const now = new Date();
  const firstPrompt = turns[0]?.prompt ?? '比较对话';
  const lastTurn = turns[turns.length - 1];
  const preview = lastTurn
    ? Object.values(lastTurn.runs)[0]?.content.slice(0, 150) ?? '比较对话'
    : '比较对话';
  return {
    type: 'chat',
    title: firstPrompt.length > 30 ? firstPrompt.slice(0, 30) + '...' : firstPrompt,
    preview,
    date: formatRelativeTime(now),
    model: `${selectedModels.length} 模型对比`,
    provider: 'compare',
    messages: turns.map((t) => ({ role: 'user' as const, content: t.prompt })),
    tags: ['多模型对比'],
    mode: 'compare',
    conversationId,
  };
}

- [ ] **Step 3: 核心并发 `runModel`（单模型流式，故障局部化）**

```typescript
// 模块级
const abortControllers = new Map<string, AbortController>();

async function runModel(
  turnId: string,
  model: SelectedModel,
  priorBranch: BranchMessage[],
  prompt: string,
  appendToBranch: boolean
): Promise<void> {
  const modelKey = toModelKey(model.provider, model.model);
  const controller = new AbortController();
  abortControllers.set(modelKey, controller);
  const startedAt = Date.now();

  // 1) 置为 streaming，写入 branchMessages（追加本轮 user prompt）
  updateRun(turnId, modelKey, (run) => ({
    ...run,
    status: 'streaming',
    startedAt,
    error: undefined,
    branchMessages: appendToBranch
      ? [...run.branchMessages, { role: 'user', content: prompt }]
      : [{ role: 'user', content: prompt }],
  }));

  try {
    const branch = get().turns.find((t) => t.id === turnId)?.runs[modelKey]?.branchMessages ?? [];
    const response = await authFetch('/api/chat', {
      method: 'POST',
      body: JSON.stringify({
        messages: branch.map((m) => ({ role: m.role, content: m.content })),
        provider: model.provider,
        model: model.model,
      }),
      signal: controller.signal,
    });
    if (!response.ok) {
      const err = await response.json().catch(() => ({}));
      throw new Error(err.error || `请求失败: ${response.status}`);
    }
    let acc = '';
    await consumeChatResponse(
      response,
      (chunk) => { acc += chunk; updateRun(turnId, modelKey, (r) => ({ ...r, content: acc })); },
      (warning) => updateRun(turnId, modelKey, (r) => ({ ...r, truncationWarning: warning }))
    );
    // 2) 完成：写入 assistant 到 branchMessages
    updateRun(turnId, modelKey, (r) => ({
      ...r,
      status: 'completed',
      completedAt: Date.now(),
      branchMessages: [...r.branchMessages, { role: 'assistant', content: acc }],
    }));
  } catch (e) {
    if (e instanceof Error && e.name === 'AbortError') {
      updateRun(turnId, modelKey, (r) => ({ ...r, status: 'stopped', completedAt: Date.now() }));
    } else {
      updateRun(turnId, modelKey, (r) => ({
        ...r,
        status: 'failed',
        completedAt: Date.now(),
        error: `${model.label} 暂时不可用：${e instanceof Error ? e.message : '未知错误'}，可重试该模型`,
      }));
    }
  } finally {
    abortControllers.delete(modelKey);
    syncTurnsToConversation(); // 持久化镜像
  }
}
```
`updateRun` 为内部 helper：按 `turnId + modelKey` 更新 `turns[].runs[modelKey]`。`syncTurnsToConversation` 调 `useConversationsStore.getState().updateComparisonTurns(activeComparisonId, get().turns)`。

**性能与持久化时机（M2）**：4 模型并发时，每模型每 chunk 都 `set` 会造成渲染抖动。`updateRun` 的内容追加用 `requestAnimationFrame` 节流（每帧最多一次 `set`），状态字段（status/耗时/错误）即时更新；`syncTurnsToConversation` 只在流式完成/失败/停止时调用（不在每 chunk 持久化），进行中内容不持久化（刷新后保留到最近完成轮，可接受）。`recordHistory` 用 `history-store.addItem`（其实现按 id 去重覆盖，等同 upsert），同一 `conversationId` 重复记录安全。

```typescript
sendComparison: async (prompt) => {
  const { selectedModels } = get();
  if (!prompt.trim() || selectedModels.length < MIN_COMPARE_MODELS) {
    set({ error: new Error(`请至少选择 ${MIN_COMPARE_MODELS} 个模型`) });
    return;
  }
  const turnId = `turn-${Date.now()}`;
  const runs: Record<string, ModelRun> = {};
  for (const m of selectedModels) {
    const modelKey = toModelKey(m.provider, m.model);
    runs[modelKey] = {
      modelKey, provider: m.provider, model: m.model, label: m.label,
      status: 'queued', content: '', branchMessages: [],
    };
  }
  const keys = Object.keys(runs);
  const turn: ComparisonTurn = {
    id: turnId, prompt, createdAt: Date.now(), runs,
    focusSlots: { left: keys[0], right: keys[1] ?? keys[0] },
  };
  // 若无激活会话则创建持久化会话
  let convId = get().activeComparisonId;
  if (!convId) {
    convId = useConversationsStore.getState().createComparisonConversation(selectedModels, prompt);
    set({ activeComparisonId: convId });
  }
  set((s) => ({ turns: [...s.turns, turn], input: '', error: null }));
  // 并发（各自独立，互不阻塞）
  await Promise.allSettled(
    selectedModels.map((m) => runModel(turnId, m, [], prompt, false))
  );
  // 首轮完成后记录历史
  recordHistory();
},

continueComparison: async (prompt) => {
  const lastTurn = get().turns[get().turns.length - 1];
  if (!prompt.trim() || !lastTurn) return;
  const turnId = `turn-${Date.now()}`;
  const runs: Record<string, ModelRun> = {};
  for (const modelKey of Object.keys(lastTurn.runs)) {
    const prev = lastTurn.runs[modelKey];
    runs[modelKey] = {
      modelKey, provider: prev.provider, model: prev.model, label: prev.label,
      status: 'queued', content: '',
      branchMessages: [...prev.branchMessages], // 继承该模型自己的分支
    };
  }
  const turn: ComparisonTurn = {
    id: turnId, prompt, createdAt: Date.now(), runs,
    focusSlots: { ...lastTurn.focusSlots },
  };
  set((s) => ({ turns: [...s.turns, turn], input: '', error: null }));
  await Promise.allSettled(
    Object.values(runs).map((r) =>
      runModel(turnId, { provider: r.provider, model: r.model, providerLabel: '', label: r.label }, r.branchMessages, prompt, true)
    )
  );
  recordHistory();
},
```

```typescript
stopModel: (modelKey) => {

retryModel: async (turnId, modelKey) => {
  const turn = get().turns.find((t) => t.id === turnId);
  const run = turn?.runs[modelKey];
  if (!turn || !run) return;
  // 重试当前轮：用该模型 branchMessages 中最后一条 user 作为 prompt
  const lastUser = [...run.branchMessages].reverse().find((m) => m.role === 'user');
  if (!lastUser) return;
  // 回退到该轮之前的历史作为 prior，重发
  const prior = run.branchMessages.slice(0, run.branchMessages.lastIndexOf(lastUser));
  updateRun(turnId, modelKey, (r) => ({ ...r, content: '', error: undefined, branchMessages: prior }));
  await runModel(turnId, { provider: run.provider, model: run.model, providerLabel: '', label: run.label }, prior, lastUser.content, true);
},
setFocus: (turnId, slot, modelKey) => {
  set((s) => ({
    turns: s.turns.map((t) =>
      t.id === turnId ? { ...t, focusSlots: { ...t.focusSlots, [slot]: modelKey } } : t
    ),
  }));
  // focusSlots 只影响 UI，不同步历史（需求 §4 约束）
},
startNewComparison: () => {
  for (const c of abortControllers.values()) c.abort();
  abortControllers.clear();
  set({ turns: [], activeComparisonId: null, input: '', error: null });
},
loadComparison: (id) => {
  const conv = useConversationsStore.getState().conversations.find((c) => c.id === id);
  if (!conv || conv.mode !== 'compare') return;
  for (const c of abortControllers.values()) c.abort();
  abortControllers.clear();
  set({
    activeComparisonId: id,
    turns: conv.turns ?? [],
    selectedModels: conv.selectedModels ?? get().selectedModels,
    mode: 'compare',
    error: null,
  });
},
reset: () => {
  for (const c of abortControllers.values()) c.abort();
  abortControllers.clear();
  set({ turns: [], activeComparisonId: null, input: '', error: null, selectedModels: defaultSelected() });
},
```
`recordHistory`：调 `useHistoryStore.getState().addItem({ id: activeComparisonId, ...createComparisonHistoryItem(activeComparisonId, turns, selectedModels), createdAt, updatedAt })`。`defaultSelected()` 由 `DEFAULT_COMPARE_MODEL_KEYS` 映射 `CHAT_MODEL_CATALOG` 得到。

- [ ] **Step 6: 持久化运行时（可选轻量）与选择器**

`comparison-store` 自身用 `persist` 仅存 `mode` 与 `selectedModels`（key `ai-chat-comparison`），会话分支数据以 `conversations-store` 为准（避免双写）。导出 `useComparisonMode`、`useSelectedModels`、`useComparisonTurns` 等 `useShallow` 选择器。

## 风险点与依赖项

- **money / token 成本**：N 模型并发 = N 次 `/api/chat` 调用 = N 次 token 扣减。必须：成本可见（「将同时调用 N 个模型」）；`retryModel` 重发但 `/api/chat` 按实际用量扣减属正常，不得因前端 bug 造成同一内容重复并发扣减；`stopModel` 终止后已产生用量按实际计（服务端已处理）。编排 bug（如同一 modelKey 重复并发）是主要风险，`runModel` 以 `turnId+modelKey` 唯一键约束。
- **并发限流/配额余量（M3）**：N 条并发请求各自经过 `/api/chat` 的限流与配额检查，匿名用户每次预扣 `CHAT_RESERVE` → 4 并发 = 4× 预扣。余额不足或限流时部分模型返回 402/429，按「失败模型不阻塞」处理（该模型卡显示失败+重试，其它模型正常）。实现时在 manual-test 验证 4 并发下不全部触发限流；若普遍触发，需在发送端对匿名/低余额给出「减少并发模型数」提示（不改变既有服务端限流策略）。
- **分支隔离正确性**：多轮最易出错。`continueComparison` 必须基于各模型自己的 `branchMessages`，绝不交叉。Task 6 步骤 4 为关键验证点。
- **既有单聊回归**：page.tsx 为 45KB 复杂文件，条件渲染改动需确保 `mode='single'` 路径零变化；改动单独成 commit。
- **持久化数据兼容**：`Conversation` 新增可选字段对旧数据向后兼容（旧会话无 `mode`，按单聊处理）。
- **故障局部化**：用 `Promise.allSettled` 而非 `Promise.all`，单模型失败不阻塞其它。
- **依赖**：`@/lib/utils/chat-stream` 的 `consumeChatResponse`、`@/lib/api/client` 的 `authFetch`、shadcn `tabs/popover/dialog`、现有 `react-markdown`/`code-block` 渲染。
