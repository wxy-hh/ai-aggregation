## 严重问题（Critical）

1. 位置：`infra/worker-rtasr/wrangler.toml` 的历史版本与供应商控制台

   问题：先前明文写入仓库的讯飞凭据已从当前工作区删除，并改为 `.dev.vars` / Cloudflare Secret，但历史中出现过的密钥仍可能有效。

   影响：只要旧密钥仍有效，获得历史仓库内容的人员可以绕过本系统直接消耗供应商资源。

   建议：在讯飞控制台立即撤销并新建凭据；将新值以 `wrangler secret put` 写入 Cloudflare，且不要提交 `.dev.vars`。这是外部系统操作，代码无法代为完成。

## 重要问题（Important）

无。此前所有重要问题均已修复：

- 视频提示词优化现在受 `withAuth` 保护，按供应商 Token 预留、结算与记录，独立记为 `video_prompt`，不占视频任务次数。
- 上传转写在服务端落盘后用 `music-metadata` 读取真实音频时长；客户端 `duration` 和文件大小不再参与账本事实。
- 实时 RTASR 先验证用户令牌并创建预留，网关按实际转发的 PCM 字节数计算秒数；首段音频转发后锁定预留，空会话释放，结束/异常/超时均回调结算。
- 资源汇总按 Token、音频秒数、图片任务和视频任务分账；额度圆环读取 `QuotaAccount.settledUnits`，不再使用混合的用量记录累计。
- 管理员仍受安全限流，但跳过普通用户每日业务请求额度与统一账本扣费。

## 次要问题（Minor）

1. 位置：`infra/worker-rtasr/src/index.ts`

   问题：浏览器会在加密 WebSocket 首帧向自有网关提交当前登录令牌，由网关换取会话预留。

   影响：网关属于可信基础设施且代码不记录该令牌，但部署日志、调试代理和监控系统必须持续避免记录 WebSocket 原始消息。

   建议：部署侧关闭或脱敏 WebSocket 消息体日志；后续如需降低信任边界，可演进为短期一次性网关会话令牌。

## 需求覆盖

| 设计要求 | 审查结论 | 证据 |
| --- | --- | --- |
| `isAnonymous` 只用于身份和初始额度 | 通过 | 计费服务与 AI 路由均基于统一 `userId`/账本；未按 `isAnonymous` 分支扣费。 |
| 匿名 3000、注册 20000、管理员无限免扣 | 通过 | 初始账户迁移与开户逻辑保持；管理员跳过预留和每日业务请求额度，仍记录审计用量。 |
| 智能对话、命理、简历、语音翻译按实际 Token | 通过（待真实上游验收） | 已走预留 → provider usage 结算；缺 usage 时进入待补账，不按固定值结算。 |
| 上传语音转写按真实时长 | 通过 | 服务端读取文件元数据，使用 `audio_seconds` 预留/结算。 |
| 实时语音转写按真实时长 | 通过 | 网关依据实际转发 PCM 字节数；首次转发锁定预留，最终秒数补账。 |
| 图片、视频生成只计任务次数 | 通过 | `image_task` / `video_task` 的 `quotaUnits` 为 0，页面独立展示次数。 |
| 非媒体文本能力不能绕过账本 | 通过 | 视频提示词优化已使用 `video_prompt` Token 计量链路。 |
| 计量展示不混合 Token、秒数、次数 | 通过 | 聚合与个人中心分列显示，额度圆环改用账本已结算额度。 |
